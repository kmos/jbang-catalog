# JBang Catalog

A [JBang](https://www.jbang.dev/) catalog of scripts and demos.

## Available scripts

| Alias | Description |
|---|---|
| `rag` | [Retrieval Augmented Generation with Debezium](debezium-jbang-rag/) |

## Usage

Run any script directly via its alias:

```
$ jbang rag@kmos
```

Or install it locally:

```
$ jbang app install rag@kmos
```

See each script's README for detailed usage and options.
